# share

可以直接拿出去讲的文档、方案和演示。

## 目录

### 演示

[**CODECUP · AI Evaluation**](CODECUP/v10/index.html) — 5 分钟分享用的 HTML 演示稿，共 18 步，五段：开场 / 流水线 / 三个坑 / 价值 / 下一步。

同一目录下的 `motion.html` 是这套视觉风格的动效样片。
